# 공유오피스 3일 무료체험 고객의 결제 예측과 이용 유형 분석

체험 1~3일차의 입·퇴실 기록으로 결제 가능성 순위를 매기고, 이용 유형 4개를 나눠 유형별로 누구에게 어떻게 연락할지 제안한 팀 프로젝트입니다.

| 항목 | 내용 |
|---|---|
| 과정 | 코드잇 데이터 분석 부트캠프 중급 프로젝트 2 |
| 기간 | 2026.09 |
| 인원 | 5명 (팀 프로젝트, 김형민 포함) |
| 도구 | Python (pandas, scikit-learn, XGBoost, LightGBM, matplotlib, seaborn), Google Colab |

## 문제 정의
체험 신청자의 방문율은 2021년 2분기 54.1%에서 2023년 4분기 79.1%로 올랐지만, 결제율은 51.7%에서 25.7%로 떨어졌습니다.
체험하러 오는 사람은 늘었는데 결제로 이어지지 않는 상황에서, 아래 두 가지를 확인했습니다.
1. 체험 기간의 어떤 행동이 결제와 관련 있는가?
2. 결제 가능성이 낮은 고객을 미리 골라 낼 수 있는가?

## 데이터
| 테이블 | 내용 |
|---|---|
| 신청 정보 | 3일 무료체험 신청일과 사용자 식별자 |
| 일별 방문 정보 | 사용자·지점별 방문일, 재실시간, 첫 입실·마지막 퇴실 시각 |
| 입·퇴실 로그 | 사용자·지점별 입실/퇴실 태그와 시각 |
| 결제 정보 | 체험 신청자의 최종 결제 여부 |
| 지점 정보 | 지점별 면적 |

부트캠프에서 제공한 데이터라 이 저장소에는 넣지 않았습니다. 분석 대상 신청자는 9,597명입니다.

## 분석 과정
**1. 전처리**
- 완전 중복 행 제거, 다른 날짜에 다시 신청한 기록 정리
- 일별 방문 정보의 시각이 로그보다 약 9시간 이르게 기록된 것을 확인하고 보정
- 입실·퇴실 태그를 짝지어 방문 단위로 다시 구성 (60분 안에 연속으로 찍힌 태그 정리, 짝 없는 태그 처리)
- 하루 체류시간 12시간 이상은 퇴실 태그 누락으로 보고 상한 처리

**2. EDA**
- 방문일수, 방문 일차 조합, 일평균 체류시간, 요일, 지점, 첫 입실 시간대별 결제율 비교

**3. 모델링**
- 학습은 2021~2022년 신청자, 평가는 2023년 신청자로 시간순 분할
- 로지스틱 회귀, 랜덤포레스트, XGBoost, LightGBM을 층화 5겹 교차검증으로 비교
- 지점별 결제율 피처(타깃 인코딩)는 폴드마다 학습 폴드로만 다시 계산해 데이터 누수 방지
- 네 모델의 교차검증 AUC가 0.598~0.606으로 차이가 폴드별 표준편차보다 작아, 설명하기 쉬운 로지스틱 회귀 선택

**4. 클러스터링**
- 방문 행동 피처로 K-평균 군집 4개 (K=4~6, 네 알고리즘 비교 후 결정, 시드 10번 변경 시 일치도 99.9% 이상)

## 결과
- 평가 데이터(2023년) AUC **0.623** (부트스트랩 95% 신뢰구간 0.598~0.647)
- 모델 점수 상위 30% 고객의 실제 결제율 45.4%, 하위 30%는 21.6% (평가 데이터 전체 33.6%)
- 이용 유형 4개: 평일 하루 방문형, 3일차 방문형, 저녁 방문형, 주말 방문형

**제안**
유형별로 결제 가능성 하위 30% 방문자를 대상으로, 비용이 적게 드는 액션(재방문 알림, 결제 리마인드 등)과 많이 드는 액션(무료 이용권, 첫 달 할인 등)을 나눠 제안했습니다. 효과가 검증된 방안이 아니라 A/B 테스트로 확인할 가설입니다.

## 한계
- 결제 시각이 없어, 체험 행동이 결제의 원인인지는 확인할 수 없습니다.
- 고객 획득 비용과 운영 비용 데이터가 없어 액션 비용은 정성적으로만 나눴습니다.
- 저녁 방문형은 2023년 하위 30%가 14명뿐이라 결제율이 불안정합니다.

## 내 역할 (김형민)
협업일지 기준으로 정리했습니다.
- 데이터 점검: 입·퇴실 결측(555건 등) 확인, 지점·방문일수 EDA
- 시간순 분할(과거로 학습, 2023년으로 평가) 설계
- 하루 체류시간 상한 논의를 처음 꺼냈고, 팀이 12시간으로 정했습니다.
- 모델 검토 단계에서 타깃 인코딩 누수와 시점 피처 문제를 찾아 피처 정리에 반영했습니다.

나머지 전처리, 모델 비교, 클러스터링, 제안은 팀이 함께 진행했습니다.
